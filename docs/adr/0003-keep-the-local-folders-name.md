# Keep the local folder's name

The product is herdr-pager, but the owner's local working copy keeps the folder name it had as the v1, voice messages over SSH. Claude Code keys this project's memory by the folder's path (`~/.claude/projects/` and the path, with each `/` as `-`), and many docs, specs and notes refer to the path; renaming the folder would orphan the memory and break those references. A published repository can be named herdr-pager whatever the local folder is called. The v1's name otherwise names only the archived v1, which stays in the private working copy.

**Status:** accepted, 2026-10-18 (program-scope grilling). It replaces the folder rename that the delivery plan had put in phase 3. Reworded on 2026-11-07 (phase 5, task 7.1): the folder's name is private, on the publish denylist, so this record no longer spells it; the decision is unchanged.
